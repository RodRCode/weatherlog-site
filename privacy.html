Privacy Policy for WeatherLog

WeatherLog · Effective and last updated: 2026-11-02

This policy describes how WeatherLog (“WeatherLog”), published by RodRCode LLC, accesses, uses, stores, and shares information, including information received from Google APIs. WeatherLog is a personal, single-user backup job, not a mobile app or website. It has no other users, and the only person who signs in with Google is its owner.

Summary

  • WeatherLog stores only public weather readings. It collects no personal data.
  • It uses one Google scope, drive.file, so it can reach only the files it creates in the owner’s Google Drive.
  • No analytics, no cookies, no ads, and no selling or sharing of data.

Google user data WeatherLog accesses

WeatherLog uses the Google Drive API (v3) with exactly one OAuth scope:

  • https://www.googleapis.com/auth/drive.file — see, create, and update only the specific Google Drive files and folders that WeatherLog itself creates.

WeatherLog does not request any other scope. It cannot see or change any other files in Google Drive, and it does not access Gmail, Calendar, Contacts, or Google profile or email information. It reads no Google user data beyond the files it created.

How Google user data is used

WeatherLog uses this access only to create a private folder in the owner’s Google Drive and to upload and update its weather log files there as a backup. It does not use Google user data for any other purpose, including advertising or training AI or machine-learning models.

What data WeatherLog stores

WeatherLog stores only public weather readings for Oak Hill Splash Park, published by the City of Carrollton through its public Perry Weather widget: temperature, feels-like temperature, wet-bulb globe temperature (WBGT), humidity, dew point, wind, rain totals, lightning delay status, air quality (AQI), and forecast snapshots. Each reading is saved with the time it was fetched and a label for which of the owner’s machines fetched it.

WeatherLog does not collect personal data or data about any Google user, and it does not use analytics, cookies, or ads.

How data is stored and protected

  • Weather readings are kept as CSV and JSON Lines files on the owner’s own computers.
  • About once an hour, those files are copied over encrypted HTTPS to a private folder in the owner’s own Google Drive. The folder is not shared.
  • The Google sign-in token is stored only in the backup tool’s configuration on the owner’s machine and is never shared.
  • Readings are kept until the owner deletes them; there is no automatic expiry. The sign-in token is kept until the owner revokes it.

How data is shared

WeatherLog does not sell, rent, share, or transfer any data, including Google user data, to anyone. The data stays in the owner’s own Google Drive and on the owner’s own computers.

Google API Services User Data Policy (Limited Use)

WeatherLog’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

  • Revoke Google access: go to myaccount.google.com/permissions, select WeatherLog, and remove its access. WeatherLog then can no longer reach Google Drive.
  • Delete the Drive copy: delete WeatherLog’s folder in Google Drive. WeatherLog never deletes or changes any other Drive files.
  • Delete local copies: stop the scheduled job and delete the local weather log files on the owner’s computers.

Children

WeatherLog is a personal tool and is not directed at children.

Changes

This policy will be updated if WeatherLog’s data practices change, and the date at the top will change. WeatherLog will not use Google user data in a new way without updating this policy first.
